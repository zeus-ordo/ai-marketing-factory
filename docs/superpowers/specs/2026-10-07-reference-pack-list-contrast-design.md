# Reference Pack List Contrast Design

## Goal

Ensure Pack names and summary text in the created Reference Pack list are dark
and readable against the white list cards.

## Scope

- Apply dark text to Pack name, active/inactive status, role, industry, and
  image-count summary in `app/content-studio/page.tsx`.
- Preserve selection, save, delete, filtering, and upload behavior.
- Preserve existing dark-surface contrast for the surrounding Content Studio
  section.
- Verify the focused Reference Pack contract, frontend build, and production
  Content Studio route.
