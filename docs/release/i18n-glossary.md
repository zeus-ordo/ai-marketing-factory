## Style Rules

1. UI label style uses concise noun phrases; avoid long explanatory text in table headers.
2. Keep operation tokens user-friendly (avoid raw backend enums in UI where possible).
3. Keep status vocabulary consistent across all modules (`running`, `pending`, `failed`, etc.).
